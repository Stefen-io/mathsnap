> **Phạm vi tài liệu:** Template để tự thực hiện daily standup trong Phase 0 → Phase 4 (30/04 – 21/05). Tự tracked, không bắt buộc push lên repo. Cap nguồn: ROADMAP.md.

---

## Cách dùng

- Tự thực hiện mỗi sáng (~10 phút), **trước** khi commit task đầu tiên trong ngày.
- Copy block markdown bên dưới vào file local hoặc note app.
- (Optional) Lưu vào `docs/standups/YYYY-MM-DD.md` nếu muốn tracking thành chuỗi.
- Không cần push lên repo nếu chỉ self-tracking.

---

## Template

```markdown
## Daily — DD/MM/YYYY

### Hôm qua

- [ ] Task A — Done / In Progress / Blocked
- [ ] Task B — Done / Cut

### Hôm nay (top 3)

- [ ] Task C (P0)
- [ ] Task D (P0)
- [ ] Task E (P1)

### Blockers

- (mô tả ngắn nếu có)

### Risks (review)

- R-9 status: ...
- Capacity remaining: Xh / 6h kế hoạch

### Cut decisions made

- (nếu có cắt P1, ghi lại lý do)
```
