# MathSnap — AI-Powered Math Tutoring Application

MathSnap là ứng dụng học toán trực tuyến được hỗ trợ bởi trí tuệ nhân tạo, giúp học sinh học toán một cách trực quan và dễ dàng bằng cách tương tác trực tiếp với nội dung.

## Additional Information

### Command Explanation

```bash
ln -sf ./CLAUDE.md ./AGENTS.md	# Link the CLAUDE.md file to the AGENTS.md file
```

- `ln -sf`: Overwrite a symbolic link to the source file in the target file
- `./CLAUDE.md`: The source file
- `./AGENTS.md`: The target file
